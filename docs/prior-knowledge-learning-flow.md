# واجهة المكتسبات القبلية — بنية النظام والـ UI/UX Wireframe

## الهدف

واجهة تأسيسية مدتها 10 أيام، يقودها وكيل الذكاء الاصطناعي «فهيم» لمساعدة طالب البكالوريا على تثبيت المفاهيم قبل الانتقال إلى التطبيق والاختبارات. التجربة ليست مؤقتًا زمنيًا؛ تنتهي جلسة اليوم عندما يثبت الطالب الفكرة بإجابة أو شرح قصير.

### حدود المسؤوليات

- **ProgramAgent**: يشرح أين يوجد الطالب في الأيام العشرة، يعرض حصص اليوم، ويتيح تعديل الوقت أو فتح الجلسة.
- **LessonWorkspace**: يحوّل الحصة إلى تجربة من ثلاث طبقات: المسار، المحادثة، والسبورة.
- **فهيم**: يوجّه ويشرح ويطلب من الطالب صياغة الفكرة، بدل عرض إجابة جاهزة.
- **المعرفة الموثقة**: تزود الشرح والتمارين بالمصادر، مع إبقاء المراجع داخل مساحة الدرس.
- **التخزين المحلي + API**: يحفظ الاستمرارية أثناء الجلسة، ثم يحفظ الملخصات والمحاولات والإنجازات المرتبطة بالحساب.

## UI/UX Wireframe

### 1. شاشة مسار المكتسبات القبلية `/program`

```text
┌──────────────────────────────────────────────────────────────┐
│ فهيم يرافقك اليوم                         [تنبيهات] [إعداد] │
│ اليوم 04 من رحلة العشرة أيام                                  │
│ خطوة هادئة اليوم تكفي...                                      │
│ [بومة فهيم]       [اليوم 4] · [3 حصص/اليوم] · [42% من المسار] │
├───────────────────────┬──────────────────────────────────────┤
│ المسار                 │ مساحة البرنامج                        │
│ ● 01  ● 02  ● 03      │ [خطة 10 أيام] [التنبيهات]             │
│ ◉ 04 أنت هنا           │                                      │
│ ○ 05  ○ 06 ...         │ اليوم 04 · الثلاثاء                   │
│                       │ ① فهم · فهيم · [ابدأ]                │
│ إيقاع اليوم            │ ② تطبيق · وكيل التمارين · [ابدأ]     │
│ فهم → تطبيق → تثبيت   │ ③ مراجعة · دليل · [ابدأ]              │
│                       │                                      │
│ [ضبط الخطة]           │ [عرض الأيام العشرة]                   │
└───────────────────────┴──────────────────────────────────────┘
```

السلوك:

- اليوم الحالي واضح بصريًا، والأيام المكتملة لا تختفي.
- الحصة لا تعتمد على وقت انتهاء ثابت؛ يظهر سبب الانتهاء الخاص بها.
- على الموبايل يتحول المسار إلى شريط أفقي قابل للتمرير، وتصبح الحصص عمودية.
- تظل التبويبات والتنبيهات قابلة للوصول بلوحة المفاتيح وبحالات focus واضحة.

### 2. جلسة فهيم `/lesson/:id`

```text
┌──────────────────────────────────────────────────────────────┐
│ [← العودة إلى المسار]  جلسة تثبيت · الفيزياء   اليوم 04/10   │
├───────────────┬───────────────────────┬──────────────────────┤
│ مسار الطالب    │ مساحة المحادثة        │ السبورة الحية         │
│                │                       │                      │
│ ✓ الفكرة       │ [فهيم + حالة التفكير] │ عنوان الفكرة          │
│ ◉ مثال محلول   │ "لنبدأ بما تلاحظه..." │ شرح قصير              │
│ ○ تمثيل بياني  │                       │                      │
│ ○ تدريب        │ رسالة الطالب         │ ┌──────────────────┐ │
│ ○ خلاصة        │ رسالة فهيم           │ │ رسم / معادلة /  │ │
│                │                       │ │ مناطق تركيز      │ │
│ [حفظ التقدم]   │ [اكتب سؤالك...] [إرسال]│ └──────────────────┘ │
│                │                       │ [قلم] [تمييز] [مسح] │
└───────────────┴───────────────────────┴──────────────────────┘
```

السلوك:

- **الطبقة الأولى — مسار الطالب**: تعرض التقدم الجزئي، وتسمح بالعودة إلى فكرة سابقة دون فقدان الجلسة.
- **الطبقة الثانية — المحادثة والسبورة**: يتغير السؤال والشرح مع المفهوم النشط، ويحفظ فهيم لحظة التوقف.
- **الطبقة الثالثة — اللوح الحي**: يوضح الرسم أو العلاقة أو موضع الخطأ، ويدعم الكتابة بالقلم والتمييز.
- عند الشاشات المتوسطة تصبح السبورة صفًا كاملًا أسفل المحادثة؛ على الهاتف تُرتب الطبقات: المسار، فهيم، السبورة.

## حالات أساسية

- **تحميل**: هيكل مطابق للمحتوى مع رسالة «نحضّر وحدتك».
- **جلسة جديدة**: فهيم يعرّف الهدف ويقترح أول ملاحظة.
- **تفكير/انتظار**: لا تتكرر الرسالة ولا يتجمد زر الإرسال بلا تفسير.
- **إجابة صحيحة**: إشارة تقدم هادئة وتفعيل المفهوم التالي.
- **إجابة تحتاج مراجعة**: إبراز أول خطوة غير صحيحة بدل كشف الحل كاملًا.
- **توقف مؤقت**: حفظ لحظة الشرح ووقت التوقف للعودة إليها.
- **جلسة مكتملة**: حفظ الملخص المختوم في الملف الشخصي وربط المفاهيم ببنك الأخطاء.

## الربط مع التبويبات الرئيسية

1. **الملف الشخصي**: يستقبل الملخص الرسمي المختوم، المعرف الخاص، ومؤشرات الأخطاء.
2. **التفاعل**: `/program` هو نقطة الدخول لمسار 10 أيام، و`/lesson/:id` هو مساحة التثبيت ثلاثية الطبقات.
3. **الكويزات والنقاط**: يعرض الالتزام اليومي والنقاط الناتجة عن إكمال الفهم والتطبيق والمراجعة، لا عن فتح الشاشة فقط.
